# TP Recorder visual reference archive

These files are the original visual materials supplied for the TP Recorder redesign.
They are kept as design references and are not loaded directly by the Android UI.

- `exec-3454e7e2-35ac-4021-8d98-f6e0ac4862ae.png`: Signal TP logo asset.
- `exec-0dabc40e-f16b-4452-a107-58d9786a5e25.png`, `exec-7b85f5a8-c0e0-443c-b26d-1e7c114ba00c.png`, `exec-d1dae87d-ca7d-4246-b493-3a948654b317.png`: UI kit and brand boards.
- The remaining `exec-*.png` files: connection, recording, recovery, sessions, and settings page references.
- `dji-mic-mini-device.png`: supplied DJI Mic Mini device reference.
